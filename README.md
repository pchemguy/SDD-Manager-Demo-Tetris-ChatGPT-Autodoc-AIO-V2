# Browser Tetris

Browser-based Tetris with a classic playable baseline and planned configurable gameplay enhancements. Development is currently in document preparation; no playable implementation has been delivered.

See the [project brief](docs/dev/PROJECT.md) for the complete intended scope and proposed gameplay decisions.

Development uses [SDD Manager](SDD-MANAGER.md). See the [AI-assisted development disclosure](AI_DISCLOSURE.md).
